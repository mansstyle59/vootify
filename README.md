## 🧱 Architecture

Vootify repose sur une architecture simple et scalable :

- **Frontend** : Interface utilisateur fluide et réactive  
- **Audio Engine** : Gestion du streaming en temps réel  
- **External Streams** : Intégration de flux audio distants  

---

## 🛠️ Tech Stack

- **Frontend** : HTML, CSS, JavaScript  
- **Mobile** : (Swift / React Native / Flutter selon build)  
- **Streaming** : HTTP Audio Streams (.mp3, .m3u8)  
- **Design** : UI sombre + effets lumineux (inspiration apps musicales modernes)
