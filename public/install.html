Installer sur iPhone

Comment ça marche

  1. Appuyez sur Installer sur iPhone
  2. Confirmez l'installation dans la popup
  3. Patientez pendant le téléchargement
  4. Si nécessaire : Réglages → Général → VPN et gestion des app → faire confiance au développeur

⚠️ Distribution ad-hoc : votre UDID doit être enregistré dans le profil de provisionnement.
