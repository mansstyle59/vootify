⬇️Installer sur iPhone

Comment installer :

  1. Ouvrir cette page dans Safari
  2. Appuyer sur le bouton ci-dessus
  3. Confirmer l'installation
  4. Aller dans Réglages → VPN et gestion
    et faire confiance au profil
⚠️ Prérequis :
Cette installation nécessite que l'UDID de votre appareil soit enregistré dans le profil de provisioning. Ouvrez uniquement depuis Safari sur iPhone.
